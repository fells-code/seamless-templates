The Next.js starter moves to `@seamless-auth/nextjs` 0.5 and `@seamless-auth/react` 0.16. The 0.5 adapter forwards the browser's pre-auth token when a magic link is verified, which seamless-auth-api 0.19.0 uses to sign in a link opened in the browser that requested it.
